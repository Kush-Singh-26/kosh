# Pre-commit Hooks for Kosh

This repository uses [pre-commit](https://pre-commit.com/) to automatically check code quality before each commit.

## Installation

1. Install pre-commit:
   ```bash
   pip install pre-commit
   ```

2. Install the git hook scripts:
   ```bash
   pre-commit install
   ```

3. (Optional) Run against all files:
   ```bash
   pre-commit run --all-files
   ```

## What It Checks

- **golangci-lint**: Runs the full linter suite
- **go-test**: Runs all tests
- **go-mod-tidy**: Ensures go.mod and go.sum are tidy

## Skipping Checks

To skip pre-commit hooks for a commit (not recommended):
```bash
git commit -m "message" --no-verify
```

## CI Integration

These same checks run in CI, so skipping locally may cause CI failures.
